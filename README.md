# 月杯・擲筊

心裡默念一個問題，擲一次筊，聽聽回應。可以擲一次，也可以連擲三次求三聖筊。純靜態網頁，不用登入，問題不會儲存或上傳。

GitHub Pages 使用 main 分支的 `/docs` 目錄。

## 檔案
- `docs/engine.js`：擲筊規則。每支筊平面、凸面各一半機率；一平一凸為聖筊，兩平為笑筊，兩凸為陰筊。連擲三次時，遇到笑筊或陰筊就停。
- `docs/data.js`：結果說明、小提醒與擲筊說明。
- `docs/app.js`、`docs/index.html`、`docs/style.css`：畫面與動畫。
- `tests/verify.js`：測試，執行 `node tests/verify.js`。會檢查判定、機率與文字用詞。
